04 — box-sizing: the pro trick

Default: box-sizing: content-box

Width 200px, but actual rendered width is 200 + 20*2 + 5*2 = 250px!

width: 200px
+ padding: 20px
+ border: 5px
= 250px wide!

Fix: box-sizing: border-box

Now the box is EXACTLY 200px wide. ✅

width: 200px
(includes padding & border)
= 200px wide

💎 The global reset every pro uses

/* Put this at the top of your CSS */
* {
  box-sizing: border-box;
}

That's it. Your life just got 10× easier.
