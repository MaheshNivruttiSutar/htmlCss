11 — overflow (content too big for its box)

Default: overflow: visible — content SPILLS OUT

This is a lot of text that definitely doesn't fit in a 300px by 150px box. Notice how the text just overflows past the bottom edge of the box, spilling into whatever is below it. This can cause messy layouts! Plus even more text and more text and more text and more text.

overflow: hidden — clipped, no scrollbar

This is a lot of text that definitely doesn't fit in a 300px by 150px box. The overflow is simply clipped — you can't see or scroll to the hidden parts. Sometimes this is what you want (like for rounded-corner images).

overflow: scroll — always shows scrollbars

This is a lot of text that definitely doesn't fit in a 300px by 150px box. Scroll me to see more! Even if the content fits, the scrollbars will still be visible (annoying on short content).

⭐ overflow: auto — scrollbars ONLY if needed (best default)

This is a lot of text that definitely doesn't fit. Scroll to see the rest! With auto, scrollbars appear only when content overflows. This is almost always what you want.
