⚠️ Vertical margin collapse

Each box has margin: 30px 0. You'd expect 60px between them, but CSS "collapses" adjacent vertical margins → the gap is only 30px.

Box 1 (margin: 30px 0)
Box 2 (margin: 30px 0)
Box 3 (margin: 30px 0)

💡 This is why gap in Flexbox/Grid is cleaner than margins!
