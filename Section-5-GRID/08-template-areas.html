08 — grid-template-areas (the most readable feature!)

Draw your layout using ASCII-like strings. Name areas, then assign them to children.

Basic page layout

grid-template-areas:
  "header  header"
  "sidebar main"
  "footer  footer";
Header
Sidebar
Main Content
Footer

Holy Grail Layout (5 areas)

grid-template-areas:
  "header header header"
  "left   main   right"
  "footer footer footer";
Header
Left
Main
Right
Footer

Empty cells with .

grid-template-areas:
  "header header header"
  ".      main   sidebar"
  "footer footer footer";
Header
Main
Sidebar
Footer

⚠️ Named areas MUST form rectangles. Diagonal layouts won't work.
