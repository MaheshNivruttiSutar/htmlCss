07 — flex-basis (starting size)

flex-basis sets the base size of an item BEFORE grow/shrink is applied. Default is auto (uses width).

Problem: different widths + flex-grow: 1 = items stay different sizes

Widths are 10%, 30%, 20%. Each item adds the same leftover space → still unequal!

Fix: flex-basis: 0 — now all items start equal and grow equally
