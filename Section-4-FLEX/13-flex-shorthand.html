13 — flex shorthand

The flex property sets grow + shrink + basis in one line.

flex: <grow> <shrink> <basis>

flex: 1 0 10px;
/* same as */
flex-grow: 1;
flex-shrink: 0;
flex-basis: 10px;

flex: 1 on all items — equal widths

Same as flex-grow: 1; flex-shrink: 1; flex-basis: 0
